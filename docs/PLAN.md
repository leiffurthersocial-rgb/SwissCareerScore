# SwissCareerScore — Implementation Plan (draft v0, for review)

Status: **implemented** (phases 0–8). This file is kept as the original plan; deviations decided
during implementation:

- Demand uses BFS BESTA recruitment difficulty by sector × qualification level (SECO's indicator
  system tables were not machine-readable); Job-Room requires authentication.
- Entry competition is a documented admission-hurdle rubric (applicant-per-place data is not
  published consistently).
- Work-life balance uses night work (SAKE 2013, ISCO major group) and usual weekly hours (SAKE 2025,
  sector); flexibility uses SAKE telework by sector.
- AI resilience uses project-assigned task shares per ISCO unit group (ILO/O*NET datasets were not
  reachable); labelled expert judgment.
- Meaning has no defensible source → null everywhere, weight 0 by default.
- Time-to-qualify scores years only; direct cost is excluded to avoid double counting (see methodology §4.7).
- Ranking is per pool (occupations vs education paths) shown in one page with a type filter.

## 2. Architecture

```
/data
  /raw/<source>/<file>         # untouched downloads (+ sha256 + retrieved_at in manifest.json)
  /sources.json                # registry: id, publisher, title, url, licence, year
  /entities/<id>.json          # one file per occupation / education path (hand-curated + ingested refs)
  /derived/*.json              # generated by scripts; never hand-edited
/scripts
  ingest-bfs-lse.ts            # PXWeb POST query -> data/raw/bfs-lse/2024.json
  ingest-*.ts                  # one per source
  build-data.ts                # validate (zod), join raw -> entity datapoints, emit derived/
  validate-data.ts             # CI gate: schema, every datapoint has url+year+confidence, no orphan sources
/src
  /lib/schema                  # zod schemas + inferred TS types (single source of truth)
  /lib/scoring                 # PURE TS: normalize, aggregate, uncertainty, sensitivity, ahp, filters
  /lib/url-state               # encode/decode weights, locks, filters, preset
  /app/[locale]/...            # next-intl routing: /, /entity/[id], /compare, /methodology, /about
  /components                  # shadcn/ui, charts (Recharts), SourceBadge popover
/docs  methodology.md, data-dictionary.md, PLAN.md
```

- Next.js App Router, fully static (SSG); scoring runs client-side on a precomputed dataset (~60–500 entities is trivial).
- next-intl (EN, DE shipped; FR, IT message files scaffolded with EN fallback).
- Vitest (engine + data validation), Playwright + axe-core smoke/a11y tests, ESLint, Prettier, `tsc --noEmit`.
- GitHub Actions: lint → typecheck → test → validate-data → build. Conventional commits enforced via commitlint (husky hook + CI check).

## 3. Data schema (TypeScript / zod)

```ts
type Confidence = 'measured' | 'estimated' | 'expert-judgment';
type MatchLevel = 'exact' | 'isco4' | 'isco3' | 'isco2' | 'isco1' | 'field' | 'education-level';

interface Datapoint<T = number> {
  value: T | null;               // null = missing, never silently filled
  unit: string;                  // 'CHF/month', '%', 'years', 'index'
  sourceId: string;              // -> data/sources.json (url, publisher, title)
  sourceUrl: string;             // deep link to table/asset
  year: number;                  // reference year of the data
  confidence: Confidence;
  matchLevel: MatchLevel;        // how closely the statistic matches THIS entity (proxy penalty)
  n?: number;                    // sample size if known
  note?: string;                 // derivation, caveats
}

interface Entity {
  id: string;                    // 'occ-polymechaniker', 'edu-efz-polymechaniker', 'edu-uh-msc-informatik'
  kind: 'occupation' | 'education';
  route?: 'vocational' | 'academic' | 'mixed';
  eduType?: 'EBA'|'EFZ'|'BM'|'BP'|'HFP'|'HF'|'FH-BSc'|'FH-MSc'|'UH-BSc'|'UH-MSc'|'ETH-BSc'|'ETH-MSc';
  name: Record<'en'|'de'|'fr'|'it', string | null>;
  codes: { isco08?: string; chIsco19?: string; sbn2000?: string; sbfiBeruf?: string };
  sector: string;                // NOGA section or field of study (ISCED-F)
  leadsTo?: string[];            // education -> occupation ids (and occupation -> typical paths)
  prerequisites?: string[];      // e.g. UH-MSc requires gymnasiale Matura + BSc
  languageRegions: ('de'|'fr'|'it'|'rm')[];      // where training/jobs exist
  raw: { [dimensionInput: string]: Datapoint<number> | Datapoint<string> }; // inputs, see §4
  meta: { addedBy: string; reviewed: string /* ISO date */ };
}
```
Adding an entry = add one JSON file; `validate-data` tells you exactly what is missing.

## 4. Dimensions (raw input → formula → direction)

Normalization for every dimension: **percentile rank** (mid-rank for ties) among entities in the comparison
pool with a non-null value, mapped to 0–100; inverted where lower raw = better.

| # | Dimension | Raw inputs (primary source) | Formula (raw) | Dir. |
|---|---|---|---|---|
| 1 | **Pay** | LSE 2024 median by age band, P25/P75 (BFS PXWeb 205); HE paths: BFS graduate survey standardized income 1y/5y after degree | `0.35·entry(≤29) + 0.65·mid(30–49)` median, CHF/month (P25/P75 shown, not scored) | ↑ |
| 2 | **Job stability** | SECO registered unemployment rate by Berufsart (fallback: SAKE ILO rate by ISCO 1-digit) | unemployment rate (annual avg) | ↓ |
| 3 | **Demand** | SECO Fachkräftebedarf indicator system (per Berufsart); Job-Room vacancies ÷ registered job seekers | shortage index (or vacancy/jobseeker ratio) | ↑ |
| 4 | **AI/automation resilience** | Task content by ISCO 4-digit (routine-cognitive, routine-manual, non-routine analytic, interpersonal, physical; Mihaylov & Tijdens 2019 method) + ILO GenAI exposure index (Gmyrek et al.) | `exposure = 0.5·RTI_norm + 0.5·GenAI_norm`; resilience = −exposure. **Always labelled estimate** | ↑ |
| 5 | **Training difficulty** (inv.) | EFZ/EBA: Qualifikationsverfahren failure rate (BFS); FH/UH: non-completion within 8y (BFS Studienverlauf) | failure / non-completion rate | ↓ |
| 6 | **Entry competition** (inv.) | Applicants per place: medicine (swissuniversities EMS), apprenticeships (Lehrstellen data where available), HF/FH aptitude tests | applicants ÷ places; null where unconstrained | ↓ |
| 7 | **Time & cost to qualify** (inv.) | Official durations (SBFI Bildungsverordnungen / berufsberatung.ch); tuition (institution fee schedules); apprentice wage vs. forgone wage | `years_from_end_of_compulsory_school` (primary) and `net_cost_CHF` shown; score uses years + 0.3·cost_pct | ↓ |
| 8 | **Career growth** | LSE age bands; LSE by "berufliche Stellung"; count of formal continuation paths (HBB/FH) | `median(≥50)/median(≤29)` (+ continuation-path bonus documented) | ↑ |
| 9 | **Work-life balance** | SAKE: usual weekly hours (full-time), share with evening/night/weekend work, part-time availability, by ISCO | standardized composite of 3 indicators | ↑ |
| 10 | **Remote/flexibility** | SAKE home-office share by ISCO 1-digit + teleworkability index by ISCO 3-digit (JRC/Sostero 2020) | `0.5·homeoffice + 0.5·teleworkability` | ↑ |
| 11 | **International mobility** | EU regulated-professions status, EQF recognition of qualification, language-dependence of work | documented rubric 0–3 per criterion → **expert-judgment** | ↑ |
| 12 | **Regional availability** | Employment by major region / language region (SAKE/STATENT), training offered per language region | evenness (1 − Gini across 7 regions); with canton/region filter → share of employment in that region | ↑ |
| 13 | **Meaning / societal value** (opt-in?) | ISSP Work Orientations "my job is useful to society" (CH sample, ISCO); COVID "systemrelevant" lists as secondary | mean agreement by ISCO group | ↑ |

### Scoring engine (pure TS, `src/lib/scoring`)
- **Weights**: user weights ≥0 → normalized to sum 100%. Locked weights stay fixed; moving one slider rescales only unlocked ones.
- **Null handling**: per entity, missing dimensions are dropped and remaining weights renormalized. `coverage = Σ weights of present dims`. Coverage < 60% → "insufficient data" badge, shown but ranked in a separate tier. Never imputed.
- **Uncertainty**: each datapoint gets σ (percentile points) from confidence (measured 4, estimated 10, expert 18) + matchLevel penalty (isco2 +6, isco1 +10, education-level +12). Seeded Monte-Carlo (1,000 draws, deterministic PRNG) → composite P10–P90 and rank range. Missing dims additionally widen the band by bounds (missing value could be 0 or 100).
- **Sensitivity**: for each dimension i, weight ×0.8 and ×1.2 (others renormalized) → 2N re-rankings. Report max rank shift per entity; **fragile** if shift ≥ 3 places or MC rank range spans > 5 places.
- **Correlated dimensions**: (a) avoid double counting by construction — Pay uses *level*, Career growth uses *ratio*, Time-to-qualify uses *duration/cost* only; (b) build-time Spearman matrix published in methodology + shown in UI when two weighted dims have |ρ| > 0.6; (c) optional "pay net of training" mode (lifetime earnings to 65 minus training cost/forgone income) that internalizes the pay↔training-time trade-off instead of counting both.
- **Hard filters** (applied before normalization? → see Q): max training years, canton/language region, language, min entry/mid salary, kind/route/eduType.
- **AHP wizard**: dims grouped into ≤6 clusters → ≤15 pairwise questions (Saaty 1–9 scale), principal eigenvector via power iteration, consistency ratio warning if CR > 0.10, result fills sliders.
- **Presets**: Balanced (derived from Swiss ISSP job-attribute importance ratings — documented mapping), Money-first, Security-first, Future-proof (AI), Low-stress, Fast-start.
- **URL state**: `?p=balanced&w=pay20.stab10...&l=pay&f=maxY4,cant-ZH,lang-de&c=id1,id2`.

### Tests (Vitest)
Percentile rank (ties, single value, all-null, direction flip), weight normalization (zero sum, locks), null renormalization & coverage threshold, MC reproducibility (seed), sensitivity fragile flag on crafted fixtures, AHP eigenvector vs. known matrices + CR, URL round-trip, data validation of every entity.

## 5. UI
- `/` — weight panel (preset chips, sliders + lock, AHP wizard dialog), filter sheet, ranked list (score, uncertainty bar, coverage, fragile badge, "add to compare").
- `/entity/[id]` — radar chart, contribution waterfall/stacked bar (weight × score per dim), all raw datapoints with `SourceBadge` (click → URL, year, confidence, match level, note), linked paths/occupations.
- `/compare?c=a,b,c,d` — up to 4 columns, overlaid radar, per-dim table.
- `/methodology` — renders docs/methodology.md. Persistent disclaimer banner/footer.
- Mobile-first, WCAG AA (contrast-checked tokens, keyboard sliders, aria-live on re-rank, chart data tables for screen readers), dark mode via `next-themes`.
