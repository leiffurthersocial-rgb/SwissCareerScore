# SwissCareerScore

Decision-support web app that scores Swiss occupations and education paths (EFZ/EBA apprenticeships,
Berufsmatura, Höhere Berufsbildung, FH, UH/ETH) across many dimensions, with fully adjustable weights.

> Scores are decision support, not career advice. See [docs/methodology.md](docs/methodology.md).

Work in progress. Setup, deploy steps and docs are added phase by phase (see [docs/PLAN.md](docs/PLAN.md)).

## Quick start

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # unit tests (scoring engine, url state, data validation)
```
